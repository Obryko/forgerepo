# Implement Issue

1. Read the issue and identify milestone, parent, acceptance criteria, and blockers.
2. Read `CLAUDE.md` and relevant `docs/`.
3. Stop and report if blocked.
4. Inspect code/tests/docs before editing.
5. Implement only issue scope.
6. Update tests.
7. Update docs/ADR if architecture or product assumptions change.
8. Run relevant validation.
9. Summarize changes and follow-ups.
